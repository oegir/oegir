# Resume Website

This repository contains a lightweight Docsify website. The site's Markdown content is stored in `docs/`, while `index.html` contains the Docsify configuration and page shell.

View the [published resume](https://oegir.github.io/resume/#/).

## Local development

See the [Docsify Quick Start](https://docsify.js.org/#/quickstart) guide for instructions on installing and using `docsify-cli`.

From the project root, start the local server:

```bash
docsify serve .
```

Open the URL reported by the CLI, typically `http://localhost:3000`.
